# ad-spend-efficiency-analysis

This project analyzes a company's marketing spend across different social platforms over one year to identify inefficiencies and optimize budget allocation.

## Approach

The analysis was conducted in four stages:

1. **Data Audit (CSV)** – Cleaned and validated the raw dataset containing impressions, clicks, spend, conversions, and revenue per platform.

2. **Initial Analysis (Excel)** – Explored high-level trends, calculated KPIs like CPC, CPA, and ROAS, and flagged underperforming campaigns.

3. **Deep Dive (SQL)** – Ran advanced queries using window functions and CTEs to rank platform efficiency and identify cost drivers.

4. **Dashboard (Power BI)** – Built an interactive dashboard for stakeholders to monitor spend efficiency and simulate budget reallocation.

## Outcome

The analysis revealed which platforms delivered the highest ROAS and which were draining budget with low returns. Recommendations from this project helped reduce wasted ad spend by reallocating budget toward top-performing channels.
